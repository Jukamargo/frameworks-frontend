# 🪻 Projeto Sudoku em JavaScript Vanilla

## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um jogo de Sudoku utilizando apenas **HTML**, **CSS** e **JavaScript Vanilla**, sem o uso de frameworks ou bibliotecas externas. O objetivo foi aplicar os conhecimentos adquiridos em sala de aula sobre desenvolvimento front-end, estrutura de páginas web e programação com JavaScript puro.

O jogo apresenta uma interface em tons pastéis de roxo, permitindo ao usuário interagir com o tabuleiro, inserir números e validar sua solução.

---

# 📚 Aula 01

Na primeira aula foram apresentados os conceitos fundamentais do desenvolvimento front-end, que servirão como base para a construção de aplicações web ao longo do curso.

## 💻 O que é desenvolvimento Front-End

Foi apresentada a área de desenvolvimento front-end, responsável pela criação da interface com a qual o usuário interage. O front-end engloba todos os elementos visuais de um site ou sistema, como páginas, botões, formulários, menus e animações.

Também foi discutida a importância de proporcionar uma boa experiência ao usuário, desenvolvendo interfaces organizadas, intuitivas e responsivas.

---

## 🏗️ Arquitetura de um site

Outro conteúdo abordado foi a arquitetura básica de uma aplicação web, compreendendo a função de cada tecnologia utilizada no desenvolvimento.

- **HTML:** responsável pela estrutura e organização do conteúdo da página.
- **CSS:** responsável pela estilização, cores, layout e aparência da interface.
- **JavaScript:** responsável pela interatividade e comportamento da aplicação.

Foi possível compreender como essas três tecnologias trabalham em conjunto para construir páginas web completas.

---

## 🌐 Introdução ao versionamento e deploy

Durante a aula também foi apresentada uma introdução aos conceitos de **versionamento de código** e **deploy**.

O versionamento permite registrar e acompanhar todas as alterações realizadas durante o desenvolvimento de um projeto, facilitando a organização, o trabalho em equipe e a recuperação de versões anteriores do código.

Já o deploy corresponde ao processo de disponibilizar uma aplicação para que ela possa ser acessada pelos usuários em um servidor ou ambiente de hospedagem.

Esses conceitos são fundamentais para o desenvolvimento profissional de aplicações web.

---

## ⚡ Introdução ao JavaScript (Vanilla JS)

Por fim, foi realizada uma introdução ao **JavaScript Vanilla**, que consiste na utilização do JavaScript puro, sem frameworks ou bibliotecas externas.

Foram apresentados conceitos como:

- Manipulação da DOM (Document Object Model);
- Seleção de elementos HTML;
- Criação e utilização de funções;
- Eventos de clique e interação com o usuário;
- Alteração dinâmica do conteúdo da página;
- Organização do código em arquivos separados.

Esses conhecimentos foram utilizados como base para iniciar o desenvolvimento do projeto Sudoku.
