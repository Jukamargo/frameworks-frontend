# 🌐 Frameworks Front-End

Repositório criado para reunir meus projetos e atividades desenvolvidos durante os estudos de **Desenvolvimento Front-End**.

Aqui estão projetos utilizando diferentes tecnologias, desde **HTML, CSS e JavaScript Vanilla** até frameworks como **React** e **Angular**, além de aplicações que trabalham com **APIs**.

O objetivo deste repositório é registrar minha evolução no desenvolvimento de interfaces web, explorando diferentes ferramentas, conceitos e formas de construir aplicações.

---

## 🚀 Projetos

### 🪻 1. Projeto Vanilla — Sudoku

**Tecnologias:** HTML5 • CSS3 • JavaScript Vanilla

Projeto desenvolvido utilizando **JavaScript puro**, sem frameworks ou bibliotecas externas.

A aplicação consiste em um **jogo de Sudoku**, permitindo que o usuário interaja com o tabuleiro, insira números e valide suas respostas.

O projeto foi desenvolvido para praticar conceitos fundamentais de Front-End, como:

- Estruturação de páginas com HTML;
- Estilização com CSS;
- JavaScript Vanilla;
- Manipulação da DOM;
- Eventos e interações;
- Funções e lógica de programação;
- Organização do código em arquivos separados.

🎨 A interface utiliza uma estética em **tons pastéis de roxo**.

🔗 [Acessar projeto no GitHub](https://github.com/Jukamargo/projeto-vanilla)

### ⚛️ 2. Primeiro Projeto React

**Tecnologia:** React

Este projeto representa um dos primeiros contatos com o desenvolvimento de aplicações utilizando o **React**.

O objetivo foi compreender a estrutura de uma aplicação React e aprender conceitos fundamentais do framework, como a criação de componentes e a organização de uma aplicação Front-End moderna.

Durante o desenvolvimento, foram explorados conceitos relacionados à construção de interfaces utilizando componentes reutilizáveis e à organização de projetos React.

🔗 [Acessar projeto no GitHub](https://github.com/Jukamargo/primeiro-projeto-react)

### 🕐 4. Projeto API Data Hora

**Tecnologias:** JavaScript • Node.js • Express • HTML • CSS • API REST

Projeto desenvolvido para praticar a comunicação entre **Front-End e Back-End** através de uma API.

A aplicação possui uma estrutura separada entre `backend` e `frontend`, permitindo que o Front-End consuma informações fornecidas pela API.

A API disponibiliza informações relacionadas à **data e hora**, enquanto a interface apresenta esses dados de forma visual para o usuário.

O projeto permitiu praticar conceitos como:

- Criação de uma API utilizando Express;
- Criação e utilização de rotas;
- Requisições HTTP;
- Consumo de API com `fetch`;
- Comunicação entre Front-End e Back-End;
- Estruturação de aplicações web;
- Separação entre servidor e interface.

🔗 [Acessar projeto no GitHub](https://github.com/Jukamargo/projeto-api-data-hora)

### 🚂 6. Primeiro Projeto Express

**Tecnologias:** Node.js • Express • JavaScript

Projeto desenvolvido como introdução ao uso do **Express**, um micro-framework para Node.js, focado na criação de rotas e construção de APIs REST de forma simples e rápida.

A atividade abordou a estruturação inicial de um servidor Back-End, recebimento de requisições JSON e a devolução de respostas. Também incluiu a preparação do projeto para deploy em plataformas de nuvem como Vercel e Render.

🔗 [Acessar projeto no GitHub](https://github.com/Jukamargo/projeto-api-express)
